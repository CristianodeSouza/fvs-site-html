# Documentacao Oficial do Projeto FVS

Esta pasta e a fonte oficial de orientacoes do projeto FVS Site HTML.

Qualquer documento enviado com briefing, revisao, regra de conteudo, SEO, GEO, design system, responsividade, deploy ou operacao deve ser convertido para Markdown e salvo aqui no repositorio. A regra do projeto e nao depender de arquivos locais soltos para consulta futura.

## Documentos Atuais

- `ACCEPTANCE_CRITERIA.md` - criterios de aceite do projeto.
- `CONTENT_STRUCTURE.md` - estrutura editorial e organizacao de conteudo.
- `DEPLOYMENT.md` - fluxo de publicacao e deploy.
- `DESIGN_SYSTEM.md` - padroes visuais, componentes, tipografia e UI.
- `MOTION_SYSTEM.md` - padroes de movimento e animacoes.
- `SEO.md` - diretrizes de SEO, indexacao e sitemap.

## Como Registrar Novas Orientacoes

1. Receber o documento ou texto do briefing.
2. Converter o conteudo para Markdown.
3. Salvar dentro de `docs/` com nome claro e estavel.
4. Atualizar este indice com o novo arquivo.
5. Fazer commit e push para o GitHub.

## Regra Operacional

Antes de executar alteracoes relevantes no site, consultar esta pasta para recuperar o contexto oficial do projeto.
