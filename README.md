# FVS Incorporações — Site Institucional

Site premium em HTML, CSS e JavaScript puro.

## Stack

- **HTML5** — Semântica e SEO
- **CSS3** — Variáveis, Grid, Flexbox
- **JavaScript Vanilla** — Interações leves
- **Vercel** — Hospedagem
- **GitHub** — Versionamento

## Estrutura

```
/fvs-site-html
├── index.html          (Estrutura principal)
├── style.css           (Estilos e variáveis)
├── script.js           (Interações)
├── README.md           (Este arquivo)
├── FVS_HTML_MASTER_SPEC.md  (Especificação completa)
│
├── /assets
│   ├── /images         (Imagens do site)
│   ├── /videos         (Vídeos)
│   └── /icons          (Ícones SVG)
│
└── /docs
    ├── DESIGN_SYSTEM.md       (Paleta e tipografia)
    ├── MOTION_SYSTEM.md       (Animações e transições)
    ├── CONTENT_STRUCTURE.md   (Narrativa e copy)
    ├── SEO.md                 (Otimização)
    ├── ACCEPTANCE_CRITERIA.md (Critérios de aceite)
    └── DEPLOYMENT.md          (Guia de publicação)
```

## Tipografia

- **Display:** Cormorant Garamond (headlines, títulos)
- **Body:** Outfit (menu, parágrafos, botões)

2. Edite os arquivos HTML/CSS/JS
3. Faça commit
4. Push para GitHub
5. Vercel publica automaticamente
